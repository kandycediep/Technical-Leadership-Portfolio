# Impact Project: Git Workflow Tutorial

*A hands-on GitHub workflow tutorial that helps new developers practice version control through a guided coding exercise.*

**Target Skills: Stakeholder Identification, Problem Solving, Technical Documentation, Developer Experience, Workflow Design**

## Task

During my internship at Liberty Mutual, I identified that new interns often struggle with learning Git and GitHub collaboration workflows before they can confidently contribute to projects. The challenge was that existing resources often explain Git concepts but do not provide a low-stakes environment to practice the full development workflow. I set out to build an interactive tutorial that allows new developers to practice the core Git workflow through a realistic, guided coding task.

## Process

I first reflected on my own experience learning Git workflows and identified the points where new developers commonly get stuck, such as understanding branches, commits, pushes, and pull requests. I designed the tutorial around a beginner-friendly practice repository where users complete the same workflow they would use on a real engineering team. I structured the experience with step-by-step instructions, checkpoints, and a small debugging task so learners could verify their progress at each stage rather than only reading about Git concepts.

## Deliverable

### Git/GitHub Workflow Interactive Tutorial

**Repository Link:** [https://github.com/kandycediep/Git-Workflow-Practice](url)

This hands-on tutorial guides new developers through the core collaboration workflow:

- Cloning a repository
- Creating a branch
- Making and testing a code change
- Staging and committing changes
- Pushing a branch to GitHub
- Opening a pull request

The tutorial includes a README.md overview and a Git-Workflow-Tutorial.md walkthrough that learners can follow step-by-step in their own development environment.

## Reflection

After sharing the tutorial with a couple interns and individuals new to this workflow, I learned that the step-by-step workflow helped make Git collaboration feel less intimidating for new developers. One person mentioned how they appreciated the explanation of why we were doing each command and also the checkpoints after every step to ensure people aren't getting lost in the middle. 

The biggest lesson I learned about leading was that effective technical resources are not just about explaining concepts, but also having the individual actually practice these skills through interactive, hands-on activities.
