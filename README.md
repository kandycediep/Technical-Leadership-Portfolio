### Why Technical Leadership?

Technical communication is critical when working collaboratively in a team where effectively explaining what you built in a simple way enables a dynamic workflow where feedback and questions flourish. Leadership especially is important in the world of tech because being successful in this field requires not only on the ability to write code, but also taking initiative to lead teams and communicating clearly.

### How to Navigate This Repo

This repository contains my reflections and technical leadership exercises completed during the KWK Technical Leadership Accelerator program. Each folder/markdown contains milestone projects achieved through each module, as well as the final impact project.

### Final Reflection

When this program started, I struggled to explain technical concepts to people without a technical background. I found myself talking in circles and included "um" and "like" in almost all my sentences. I was left feeling like I never quite landed the point I was trying to get across. Throughout this program, I’ve found myself growing immensely in this realm. During pair programming as the Navigator, I learned to communicate my thinking clearly in real time and how giving individuals space to process is just as important as explaining well. That same instinct, that understanding sticks better through doing than through being told, shaped my Impact Project. My project revolved around the bottleneck of new interns at my internship who kept getting stuck learning Git/GitHub before they could contribute. I built a hands-on tutorial that lets them practice the real workflow (branching, committing, pushing, opening a pull request) instead of just reading about it. Watching someone move from hesitant to confident, checkpoint by checkpoint, was more rewarding than solving the problem myself ever was. Now, I can communicate technical ideas clearly, efficiently, and in a way that lands with those that I'm speaking to.
